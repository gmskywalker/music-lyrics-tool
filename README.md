# AAA 音乐歌词工具

独立的 Windows 本地音乐歌词搜索、结构校验、音频模型复核与安全写入工具。不会读取或修改“音乐信息与封面一键整理”的设置和数据。

## 主要功能

- 扫描文件夹或多选音乐，新扫描项目默认不勾选。
- 并发搜索网易云、QQ 音乐和酷狗，按歌曲元数据过滤后最多请求少量歌词；国内来源没有有效结果时才尝试 LRCLIB，连接失败会暂时跳过该来源。
- 联网候选必须先通过 LRC 解析、时间顺序、有效行数和音频时长检查；不合格候选不会显示。
- 使用本地 faster-whisper 模型比较音频识别文字、歌词内容和时间锚点；自动语言误判成非中文时，针对中文歌词重新识别并选择可靠结果。
- 自动优先 NVIDIA GPU；同级数据文件夹包含官方 CUDA 12/cuDNN 9 运行库，加载失败时自动回退 CPU。默认 small，medium 和 large-v3 按需下载。
- 联网搜索、音频复核和写入任务均可暂停或终止；终止会保留已完成歌曲的结果，并等待当前网络请求或单文件安全写入结束。
- 每完成一首音频复核立即刷新对应列表行，并可一键选择全部“通过/已自动校正”歌曲。
- 后台继续复核其他歌曲时，已经完成的歌曲仍可切换、播放、拖动进度和查看同步歌词；只有需要替换音频文件的写入阶段才锁定试听。
- Qt 原生播放器可试听、点击或拖动进度；音量收进弹出按钮并记忆设置。人工浏览歌词时短暂停止自动跟随，4 秒后恢复；双击可见歌词可稳定跳转并立即恢复跟随。
- 支持由音频模型自动判断语言，也可分别指定国语（`zh`）、粤语（`yue`）或英语（`en`）。
- 同一首音频只识别一次，再比较全部有效候选；使用拼音容忍少量同音字识别误差，但保留原字、版本时长、覆盖范围和分散锚点门槛。
- 仅在锚点数量、覆盖范围、残差和偏移幅度都可靠时自动校时。大幅偏移会被视为漏识别或重复段落错配，禁止自动修改。
- 支持导入和编辑歌词；候选编辑页及试听页都有撤销和重做，试听页可选择将当前句与其余正文一起移动。整体移动最小 0.1 秒，片头署名保留原位。
- 试听确认后可直接写入当前歌词，仍使用临时副本、备份、复读和失败回滚。
- 强制写入未通过音频复核的歌词时，可在当前程序运行期间记住确认；退出后自动恢复询问，不写入持久设置。
- 可独立选择嵌入音频、生成同名 LRC，也可同时选择；至少保留一种。
- 写入前释放播放器对音频的占用；临时副本写入、短暂文件占用重试、原标签与封面快照比对、复读验证、失败回滚和备份。
- 设置、模型、日志、缓存和备份全部保存在 EXE 同级的 `音乐歌词工具数据`。

## 开发运行

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\app.py
```

## 构建

```powershell
.\build.ps1
```

构建结果位于 `portable`，包括一个 `AAA音乐歌词工具.exe` 和一个 `音乐歌词工具数据` 文件夹。识别模型首次使用时按需下载到数据文件夹，不塞入 EXE。GPU 运行库约 1.50 GiB，必须和数据文件夹一起移动才能保证 CUDA 复核可用。

## 隐私

本地模型直接读取音频，音频文件不会上传。联网歌词来源只接收用于搜索的标题、艺术家、唱片集和时长。可选的音频指纹后备识别尚未默认启用。

酷我现有公开网页接口在直连测试中返回反爬/空结果；汽水音乐暂无稳定且可验证的公开歌词接口。本工具不伪造它们的可用性，后续有合规稳定接口再接入。
